# 深度学习项目设计手册

> 配套《深度学习学习笔记》（第 1~15 章，即 `1.深度学习简介` ~ `15.CNN 核心`）。全手册共两部分：
> - **第一部分**：按章节设计的**巩固练习项目**，每章 2~3 个，紧扣该章知识点，难度高的章 3 个、简单的章 2 个；
> - **第二部分**：把相关性强的章节**组合成"部分"**，给出**强业务性质的生产项目**，数据均为自编示例数据（已标注口径）。
>
> 每个项目都标注：难度（★易 / ★★中 / ★★★难）、练习到的知识点、数据来源、任务拆解、验收标准。建议按顺序做，学完一章做一章。

---

## 使用说明

| 标记 | 含义 |
| --- | --- |
| ★ | 简单：1~2 天内完成，验证单个知识点 |
| ★★ | 中等：2~4 天，综合本章多个知识点 |
| ★★★ | 高：3~7 天，接近真实训练实验，建议写成报告 |

> 每个"巩固项目"建议**先动手写、后看笔记与 `DL.ipynb` 对应单元**，跑出来的结果（loss 曲线、决策边界、特征图）保存截图，最终汇总成一份属于自己的"实验手册"。

> **关于数据来源的两类标注**（全文通用）：
> - **公开数据集**：MNIST、Fashion-MNIST、CIFAR-10 等，笔记中已大量使用，可直接 `torchvision` 加载；
> - **自编数据**：用 `numpy` 随机生成或用 `PIL` 合成的示例数据，口径在项目内给出，方便你快速跑通、无需下载。

## 第 2 章　感知机（★~★★ 章 → 2 个）

**本章知识**（见 `2.感知机`）：感知机结构、决策边界、权重更新规则 `w←w+η(y−ŷ)x`、线性可分的局限、XOR 不可分。

### 项目 2-1（★）从零手写感知机·胖瘦分类
- **练到**：权重更新规则、决策边界
- **数据**：自编 200 人数据，特征 `x1=身高(cm)`、`x2=体重(kg)`，归一化到 0~1，标签 0=偏瘦 1=偏胖（线性可分）。这正是笔记第 3 节"预测身材偏胖还是偏瘦"的案例。
- **任务**：仅用 numpy 手写感知机（不用 PyTorch），从权重全 0 开始迭代；把每次更新后的决策边界画在散点上，观察边界如何移动直至分开两类。
- **验收**：训练后训练准确率 100%；能打印出最终的 `w,b` 并画出直线 `w1*x1+w2*x2+b=0`。

### 项目 2-2（★）构造 XOR，证明感知机之死
- **练到**：线性可分 vs 不可分、局限
- **数据**：构造 4 个样本（00→0、01→1、10→1、11→0），即 XOR（笔记第 4 节"深度学习的寒冬"）。
- **任务**：用项目 2-1 的感知机去训练，观察 loss 永远降不到 0；用 matplotlib 画出 4 个点，验证"不存在一条直线能分开它们"。
- **验收**：训练收敛不了（或震荡）、准确率≤75%；报告里写清楚为什么单层做不到。

## 第 3 章　MLP（★★ 章 → 3 个）

**本章知识**（见 `3.MLP`）：复杂功能由简单模块组合、多层感知机构造、激活函数打破线性、万能逼近定理。

### 项目 3-1（★）numpy 实现两层网络解 XOR
- **练到**：层间全连接 + 非线性激活
- **任务**：用 numpy 手写一个"输入 2 → 隐藏 2 → 输出 1"的两层网络（隐藏层用 tanh 或 ReLU），手写前向 + 简单梯度，训练它学会 XOR（对照笔记第 1 节"用两层感知机解决 XOR"：两个隐藏神经元分别学"至少一个为 1"与"不能同时为 1"）。
- **验收**：4 个样本全部预测正确；能画出隐藏层两个神经元各自学到的"分割线"。

### 项目 3-2（★★）万能逼近定理验证
- **练到**：单隐藏层 MLP 逼近任意连续函数（笔记第 4 节）
- **任务**：用 numpy 构造单隐藏层 MLP（隐藏层神经元数取 2/8/32），分别去拟合 `sin(x)`、`|x|`、`x²` 在 [-3,3] 的曲线；画出拟合曲线与真实曲线。
- **验收**：神经元越多拟合越贴近；报告指出"表达能力≠训练能力"（笔记原文：表达能力与训练能力是两个不同的问题）。

### 项目 3-3（★★）MLP 调宽 vs 调深
- **练到**：深度/宽度对能力的影响
- **任务**：在合成回归数据上比较：宽而浅（如 64 神经元单隐层）vs 窄而深（如 4 层×16）两种 MLP 的拟合效果与参数量。
- **验收**：给出两者 loss 对比表与曲线，说明哪种更优及原因。

## 第 4 章　反向传播（★★★ 章 → 3 个）

**本章知识**（见 `4.反向传播`）：前向/反向传播、链式法则、计算图、自动微分、ReLU 导数、梯度正负含义。

### 项目 4-1（★★）手写反向传播 vs PyTorch autograd 对照
- **练到**：链式法则、梯度计算
- **任务**：手写一个 2 层网络的 forward + 反向（手工实现每层梯度），再用 `loss.backward()` 得到同一网络的梯度；**逐参数对比**两者是否一致（允许浮点误差 1e-6）。
- **验收**：逐层打印手写梯度与 autograd 梯度，全部相等；写清推导过程。

### 项目 4-2（★★）计算图梯度可视化
- **练到**：计算图、沿路径相乘
- **任务**：对笔记第 5 节那个极简网络（w1,w2,w3），画出计算图，标注每个节点值；用手工链式法则算出每个权重梯度（笔记已给出 w1=18、w2=12、w3=-36），并画箭头标出"责任大小"。
- **验收**：梯度数值与笔记推导一致；能说清"梯度正/负的含义"（正→增大会让损失上升，要减小；负→反之）。

### 项目 4-3（★★★）从零实现迷你自动微分引擎
- **练到**：自动微分的本质
- **任务**：定义一个 `Tensor` 类，支持 `+`、`*`、`ReLU`、`MSE`，实现 `.backward()`（反向拓扑排序、局部梯度相乘回传）。用它训练一个线性回归（逼近 `y=3x+2`）。
- **验收**：训练 loss 收敛到接近 0；梯度结果与 PyTorch 对照一致；写清实现思路。

## 第 5 章　激活函数（★★★ 章 → 3 个）

**本章知识**（见 `5.激活函数`）：Sigmoid/Tanh/ReLU/LeakyReLU/GELU/Swish(SiLU) 的优劣、梯度消失、非零中心、适用场景。

### 项目 5-1（★★）激活函数大比武（MNIST MLP）
- **练到**：各激活收敛速度与精度
- **数据**：MNIST 60k 训练 / 10k 测试（公开数据集）。
- **任务**：用同一个 2~3 层 MLP，分别换 Sigmoid/Tanh/ReLU/LeakyReLU/GELU/SiLU，各训练相同 epoch，记录每 epoch 的训练 loss 和测试 acc，画成对比曲线。
- **验收**：同一张图上画出 6 条 acc 曲线；结论能对应"ReLU 系快且高、Sigmoid 慢"。

### 项目 5-2（★★）梯度消失/爆炸复现实验
- **练到**：深层下不同激活的梯度行为（笔记第 3 节 Sigmoid 硬伤）
- **任务**：构造 10 层 MLP，分别用 Sigmoid 和 ReLU；打印每层回传梯度的平均范数，观察 Sigmoid 越深越小（消失）、ReLU 相对稳定。
- **验收**：画出"层号 vs 梯度范数"两条曲线，Sigmoid 明显衰减（可对照笔记 `0.25⁵≈0.001` 的推导）。

### 项目 5-3（★★★）自创激活函数并测评
- **练到**：对激活函数的深刻理解
- **任务**：自定义一个激活函数（如 `f(x)=x·ReLU(x)` 等），验证其可导性，接入 MNIST MLP 与 ReLU 对比；写出分析（导数、是否零中心、是否饱和）。
- **验收**：给出新函数表达式、导数推导、训练曲线、与 ReLU 的对比结论、优缺点报告。

### 项目 6-2（★★★）从零实现 Momentum 与 Adam

## 第 7 章　损失函数（★★ 章 → 3 个）

**本章知识**（见 `7.损失函数`）：MSE、BCE、Softmax+CE、各自的概率假设、梯度干净度、选型原则。

### 项目 7-1（★★）复现"MSE 配 Sigmoid 梯度消失"
- **练到**：CE 比 MSE 适合分类的根本原因（笔记第 2 节"错的越离谱、梯度越小"）
- **数据**：自编二分类小数据。
- **任务**：同一模型分别用 `MSE+Sigmoid` 和 `BCEWithLogitsLoss` 训练，对比收敛曲线；打印输出层梯度大小。
- **验收**：MSE 版梯度趋近 0 学不动、BCE 版正常收敛；报告里写清推导 `∂L/∂z`（MSE 版多乘一个饱和因子 σ'(z)，BCE 版恰好约掉）。

### 项目 7-2（★★）回归损失对抗离群点
- **练到**：MSE 对离群点敏感、Huber 更稳
- **数据**：合成回归数据 + 人为注入 3 个极端离群点。
- **任务**：同一模型分别用 MSE / MAE / Huber 训练，对比测试集 MAE。
- **验收**：表格列出三种损失的测试误差；结论"Huber 兼顾鲁棒性与梯度"。

### 项目 7-3（★★★）为类别不平衡设计加权损失
- **练到**：损失函数是"任务目标"的载体
- **数据**：自编 10000 条二分类数据，正样本仅占 5%。
- **任务**：对比朴素 CE 与加权 CE（正样本权重 = 负样本数/正样本数），关注**召回率**而非整体 acc。
- **验收**：给出两版的混淆矩阵；加权版召回率明显提升，并解释为什么整体 acc 可能略降。

  4. 评估 AUC / LogLoss / 校准度；调决策阈值到业务最优。
- **业务交付**：CTR 模型 + 一份"点击率分桶校准表"（预测 0.03 的桶实际点击率应≈0.03），评估是否校准。
- **验收**：AUC ≥ 0.75；LogLoss 显著低于基线；能说明如何选择上线阈值。

### 项目 B-4（★★）客户终身价值 LTV 预测（回归 + 不确定性提示）
- **业务背景**：电商要预测新客户未来 12 个月能给公司带来多少 GMV，据此决定投放预算。
- **自编数据**（口径示例）：`ltv.csv`，80,000 行——特征：首单金额、首单品类、渠道、注册月、是否会员、首周浏览等；标签 `ltv_12m`（未来 12 个月 GMV）。
- **用到的本章知识**：回归 + Huber/MSE（第7）、完整训练流程（第13）、正则化防过拟合（第12）。
- **任务拆解**
  1. 处理长尾 LTV（很多客户价值极低、少数极高），选 Huber 或对目标做 log 变换；
  2. 训练回归 MLP，早停；
  3. 除预测值外，给出"预测可能高估/低估"的风险提示（如分段误差）；
  4. 产出一份"该客户值不值得投流"的分档建议。
- **业务交付**：LTV 预测 + 分档表（值得投/谨慎/不投），便于市场部直接使用。
- **验收**：RMSE 低于基线 20%+；能解释长尾分布下为何不用纯 MSE。

## 部分 C　计算机视觉生产业务
### （组合章节：第 14 CNN 第一课 · 第 15 CNN 核心）

> **该部分回答的核心问题**：把"图像"数据做成生产能用的分类模型，用到 CNN 全部能力。

### 项目 C-1（★★★）工业产品表面缺陷检测（图像多分类）
- **业务背景**：某金属零件厂要在产线上自动检测产品表面缺陷，替代人工目检。缺陷分为：**划痕 / 污点 / 空洞 / 毛刺 / 完好**。
- **自编数据**（口径示例）：用公开缺陷数据集或自生成 20,000 张灰度图（如钢板缺陷数据集可作为来源之一）；也可用 `numpy`/`PIL` 合成：在干净底图上随机叠加不同纹理作为"缺陷"。5 类，完好类最多、缺陷类少（不平衡）。
- **用到的本章知识**：CNN 特征提取（Conv/ReLU/Pool）、输出通道、Flatten→Linear、多分类 CE、数据增强（第12章可配合）、类别不平衡。
- **任务拆解**
  1. 构造/收集图像，划分 train/val/test；
  2. 设计 CNN（Conv→BN→ReLU→Pool 若干块 + Flatten→Linear）；
  3. 训练，重点看**缺陷类召回率**（漏检缺陷 = 产线放行次品，代价高）；
  4. 可视化几个特征图，检查模型是否关注到"缺陷区域"。
- **业务交付**：检测模型 + 一份"质检报告"：各缺陷类 precision/recall、误报率、漏报率、产线吞吐估算。
- **验收**：完好类准确率高且缺陷类召回率 ≥ 0.85（高价值）；给出混淆矩阵与缺陷样例可视化。

### 项目 C-2（★★）电商商品图片自动分类
- **业务背景**：电商平台上架商品需自动识别图片中的商品大类（服饰 / 鞋靴 / 箱包 / 数码 / 美妆 …），用于搜索与类目管理。
- **自编数据**（口径示例）：可用公开商品图片集（如 Fashion-MNIST 升级版 / CIFAR-10 类比）；若纯自编，用简单几何合成图代表几大类（如不同形状/颜色代表不同商品类）。建议用公开数据集保证效果。
- **用到的本章知识**：RGB 彩色图像输入（3 通道）、CNN、数据增强、池化与通道递增。
- **任务拆解**
  1. 加载彩色图像 + 训练集增强 / 测试集稳定；
  2. CNN（输入 3 通道）分类；
  3. 评估 top-1/top-3 准确率；
  4. 做"被分错的样本"难例分析。
- **业务交付**：分类模型 + 难例分析报告，说明下一步（如换更强骨干、加数据）的方向。
- **验收**：top-1 ≥ 0.85；能列出 5 个以上误分类典型样例并分析原因。

### 项目 C-3（★★）票据图像自动分类（为 OCR 做前置处理）
- **业务背景**：财务共享中心收到大量票据扫描件，需先自动分类为**发票 / 收据 / 合同 / 银行回单**，再送入 OCR 提取关键字段，节省人工分拣。
- **自编数据**（口径示例）：用公开文档/票据分类数据集，或用合成方式生成不同版式的四类票据图。
- **用到的本章知识**：CNN 图像分类 + 数据增强（旋转/亮度/平移，模拟扫描质量差异）。
- **任务拆解**
  1. 构建四类票据图像集，模拟不同扫描角度/亮度；
  2. CNN 分类；
  3. 评估在"旋转/模糊"扰动下的鲁棒性（增强是否有效）；
  4. 输出：分类置信度 + 低置信样本进入人工复核队列。
- **业务交付**：票据分类模型 + 一份"自动分拣 → 人工复核"流程建议（置信度阈值策略）。
- **验收**：四类 acc ≥ 0.9；证明数据增强提升了旋转/模糊鲁棒性。

## 部分 D　端到端综合旗舰项目（★★★ 最高优先，给 2 个）
### （组合章节：全部 1~15 章）

> **该部分回答的核心问题**：一个真实业务系统 = 结构化数据建模 + 图像模型 + 完整工程管线 + 可视化交付，把前面所有能力串成**一个可交付的业务解决方案**。

### 项目 D-1（★★★）智能"样品质检 + 客户风险"综合平台
- **业务背景**：某制造企业的供应商管理部，需要一套系统：既能对**新到的来料（图像）自动质检**，又能对**供应商历史合作数据（表格）做风险评级**，并把两者合并成一份"供应商健康报告"。
- **自编数据**：来料图像（合成缺陷图，复用 C-1）+ 供应商合作表（交货准时率、退货率、价格波动、合作年限、投诉数 → 风险等级 0/1/2）。
- **用到的全部知识**：CNN（C 部分）+ MLP 分类（A 部分）+ 工程管线：BN/Dropout/AdamW/早停/调度（B 部分）+ 数据增强 + 损失选型。
- **任务拆解**
  1. 两个子模型：图像质检 CNN + 供应商风险 MLP；
  2. 各自按生产流程训练、评估、存 checkpoint；
  3. 设计一个"综合健康分"融合规则（质量分 × 权重 + 风险分 × 权重）；
  4. 输出可视化看板：各供应商健康分排序、风险分布、质检缺陷统计。
- **业务交付**：两个模型 + 一份综合报告（含融合规则说明）+ 可视化看板。
- **验收**：两个子模型指标达标（同 C-1/A-1）；综合分能识别出"质量好但合作风险高"的供应商；报告完整可交给业务部门。

### 项目 D-2（★★★）电商"智能分类 + 销量预测"一体化系统
- **业务背景**：电商平台要打通两条链路：**新商品自动打类目（图像+属性）** 与 **该商品未来销量预测（表格）**，用于自动上架与补货。
- **自编数据**：商品主图（图像，分类用）+ 商品属性/销售历史（表格，销量回归用）。
- **用到的全部知识**：CNN 图像分类（C 部分）+ MLP 多分类/回归（A 部分）+ 完整训练管线（B 部分）+ 数据增强 + 正则化。
- **任务拆解**
  1. 图像分类模型识别商品大类（对应 B-2 的类目，改用图像）；
  2. 表格回归模型预测上架后 30 天销量（对应 A-3）；
  3. 两个模型的预测合并：高销量 + 类目明确的商品优先上架；
  4. 交付一套端到端脚本：输入一张图 + 一份属性表 → 输出类目 + 销量预测 + 上架建议。
- **业务交付**：一体化推理脚本（单文件可运行）+ 评估报告 + 上架决策规则。
- **验收**：图像分类 top-1 ≥ 0.85、销量预测 MAE 达标；端到端 demo 输入样例即输出完整结论；代码结构清晰、可复现。
