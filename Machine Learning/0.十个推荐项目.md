## 一、简单（3 个，适合刚学完，快速上手练手）

### 项目 1：泰坦尼克号生存预测（分类）

- 数据集：sklearn / Kaggle Titanic
- 任务：根据乘客信息预测是否生还（二分类）
- 核心技术：缺失值填充、特征工程（类别编码）、逻辑回归、随机森林、混淆矩阵、交叉验证
- 练习重点：**数据清洗、类别特征处理、特征重要性分析**

> 输出：完整建模流程，输出准确率、ROC‑AUC，提交预测 csv。

### 项目 2：波士顿 / 加州房价预测（回归）

- 数据集：`sklearn.datasets.fetch_california_housing`
- 任务：根据房屋特征预测房价
- 核心技术：标准化、线性回归、Ridge/Lasso 正则、随机森林回归、MAE/MSE/R²、学习曲线
- 练习重点：回归评估指标、正则化对抗过拟合、特征重要性

### 项目 3：鸢尾花 / 葡萄酒数据集多分类

- 数据集：sklearn 内置 wine /iris
- 任务：多分类，区分不同品种
- 核心技术：PCA 降维、SVM、KNN、决策树
- 练习重点：PCA 可视化、多分类评估（macro‑recall）、网格搜索调参 GridSearchCV

## 二、中等（5 个，最关键，练特征工程、调参、完整项目闭环）

### 项目 4：信用卡欺诈检测（不平衡二分类）

- 数据集：Kaggle Credit Card Fraud
- 任务：识别信用卡盗刷交易（样本极度不平衡）
- 核心技术：重采样 SMOTE、类别权重、逻辑回归、随机森林、XGBoost；评估不能只用准确率，用**召回率、精确率、F1、AUC**
- 练习重点：不平衡数据集处理，业务视角评估（宁愿误判也不要漏过欺诈）

### 项目 5：客户流失预测（电信用户流失）

- 数据集：Kaggle Telco Customer Churn
- 任务：预测哪些客户会流失，帮助企业做挽留
- 核心技术：特征编码、特征筛选、XGBoost 分类、SHAP 简单可解释分析
- 练习重点：业务理解，哪些因素最容易导致客户流失。

### 项目 6：电商评论情感分析（文本分类）

- 数据集：Kaggle 京东 / 亚马逊评论数据集
- 任务：文本 → 正向 / 负向情感二分类
- 核心技术：TF‑IDF 文本向量化、朴素贝叶斯、逻辑回归、随机森林

> 不用深度学习，纯传统机器学习 NLP

- 练习重点：文本预处理（去标点、停用词），文本特征构建。

### 项目 7：用户分群（K‑Means 聚类）

- 数据集：Kaggle Mall Customer 商场用户数据集
- 任务：无监督学习，根据消费、年龄做客户分群
- 核心技术：标准化、K‑Means、肘部法则、轮廓系数、聚类结果可视化
- 练习重点：无监督模型评估，业务解读每一类人群画像。

### 项目 8：二手车价格预测（真实脏表格回归）

- 数据集：Kaggle Used Car Dataset
- 任务：根据车龄、里程、品牌、车型预测二手车售价
- 核心技术：大量脏数据清洗、类别特征 OneHot/LabelEncoder、XGBoost 回归、异常值处理
- 练习重点：真实世界脏数据处理，是面试高频项目。

## 三、困难（2 个，接近竞赛 / 工程级别，适合简历项目）

### 项目 9：房价特征竞赛项目（特征工程大比拼）

- 数据集：Kaggle House Prices‑Advanced Regression Techniques
- 任务：预测房屋售价，Kaggle 经典入门竞赛
- 核心技术：大量缺失值处理、特征衍生（组合特征、对数变换处理偏态分布）、特征筛选、Stacking 模型融合（线性回归 + XGBoost+LightGBM），交叉验证策略
- 练习重点：**高阶特征工程、模型融合、避免数据泄露**，非常适合写简历。

### 项目 10：异常检测：工业设备故障检测（无监督 + 半监督）

- 数据集：Kaggle Machine Failure / 工业传感器数据集
- 任务：从传感器时序表格数据识别设备异常故障；故障样本极少
- 核心技术：IsolationForest 孤立森林、One‑Class‑SVM；特征衍生（滑动窗口统计量），评估用召回率
- 练习重点：无监督异常检测，业务场景：工业运维，简历亮点项目。

# 学习路线建议

1. 先做完 3 个简单项目，把**完整流水线**跑通：加载数据→EDA 探索分析→清洗预处理→划分训练测试→训练模型→评估→输出结果。
2. 重点啃中等 5 个项目，这是机器学习核心能力；其中「信用卡欺诈、二手车预测、文本情感」三个强烈建议完整保存作为简历 demo。
3. 最后做 1‑2 个困难项目，不要贪多，困难项目耗时很长，重点练习特征工程、模型融合、防止数据泄露。

> 每个项目建议输出：
> ①完整可运行代码 ②EDA 可视化图表 ③评估结果 ④简单 markdown 报告，方便写简历。
